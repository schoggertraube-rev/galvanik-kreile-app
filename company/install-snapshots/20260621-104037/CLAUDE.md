## Pflichtregeln

1. Vor jeder grossen UI- oder Workflow-Aenderung muss ein Zielentwurf entstehen.
2. Bestehende UI ist keine unveraenderliche Vorgabe.
3. Jede Product Mission muss den USP und alle relevanten Nutzerzwillinge pruefen.
4. Kein Bau ohne Daten-, Architektur-, UX-, Security-, Performance- und QA-Freigabe.
5. Kein fertig ohne DB -> Server -> UI -> Persistenz -> Reload -> Live-Nachweis.
6. Audit und Belastungstest werden bei Bedarf explizit aufgerufen.
