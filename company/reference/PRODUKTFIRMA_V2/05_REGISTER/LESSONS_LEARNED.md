# LESSONS_LEARNED

Nach jeder Mission gepflegt vom Knowledge Officer. Relevante Lessons werden in Subagent-Prompts gespiegelt.

| Datum | Mission | Was funktionierte | Was nicht | Konsequenz / Regel-Update |
|---|---|---|---|---|
| _Beispiel_ | _Mission_ | vertikaler Slice hielt Scope klein | Agent wollte Akzeptanzkriterium umschreiben | Hook „verlange-beweis" verschärft |

Bekannte Drift-Muster (dauerhaft wachsam): voreilige Fertig-Meldung · Akzeptanzkriterien umschreiben · Planungsdatei statt Code · Mock/Math.random nach Entfernung · unautorisierte Löschung · Hex statt CI-Token · englische Labels · node -e für TSX · DB-Passwort inline.
