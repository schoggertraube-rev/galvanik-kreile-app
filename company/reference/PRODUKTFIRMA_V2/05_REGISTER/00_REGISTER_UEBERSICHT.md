# REGISTER — Übersicht

Die Register sind das Gedächtnis und das Audit-Log der Firma. Jede ist eine Tabelle, die fortlaufend gepflegt wird. So bleibt nachvollziehbar, was passiert, wer arbeitet, was bewiesen ist.

| Register | Zweck |
|---|---|
| IDEA_REGISTER | jede Idee mit Status im Lebenszyklus |
| MISSION_BACKLOG | aktive/geplante Missionen, WIP-Kontrolle |
| DEFECT_REGISTER | Fehler nach Schweregrad (P0–P3) |
| DECISION_LOG | Stakeholder- und Architekturentscheidungen |
| EVIDENCE_LEDGER | Beweis-Artefakte + Verifier-Gegenzeichnungen |
| LESSONS_LEARNED | was funktioniert hat / nicht — Lernkreislauf |
| AGENT_ROSTER_STATUS | wer ist aktiv/standby/gekündigt (hire/fire-Log) |
| RISK_REGISTER | offene Risiken, Red-Team-Funde, Drift-Verstöße |

Diese Dateien sind Vorlagen mit Beispielzeile. Die Firma füllt sie im Betrieb.
