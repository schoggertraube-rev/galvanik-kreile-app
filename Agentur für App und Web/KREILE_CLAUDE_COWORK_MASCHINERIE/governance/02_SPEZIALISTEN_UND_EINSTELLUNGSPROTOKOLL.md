## Spezialistenlücke

Ein Spezialist fehlt, wenn keine vorhandene Rolle die Fachfrage belastbar abdecken kann, nur Vermutungen geliefert werden, eine neue Spezialdomäne berührt wird oder eine Entscheidung ohne unabhängige Prüfung bliebe.

## Einstellungsantrag

```text
SPECIALIST_REQUEST-ID:
fehlendes Fachgebiet:
konkrete Frage:
warum vorhandene Rollen nicht genügen:
benötigte Quellen:
benötigte Tools:
zulässige Änderungen:
erwartete Ausgabe:
Abnahmekriterien:
Laufzeit: einmalig / projektweit / paketbezogen
```

## Einstellung

Der Projektleiter prüft Bedarf und Dubletten, definiert Zuständigkeit, legt eine Agentendatei an, trägt die Rolle im AGENT_ROSTER ein, begrenzt Tools und Rechte und ordnet eine unabhängige Abnahme zu.

## Keine vorgetäuschte Expertise

Ein Agent muss Wissenslücken benennen, Primärquellen recherchieren, einen Spezialisten anfordern oder eine Annahme markieren.
