## Ziel-Umbausequenz

1. Manifest/Server-Fassade und app-neutralen Host-Port-Vertrag ergänzen.
2. Vorwärtsmigration für append-only Permission-/Approval-Events, Views, Indizes, Trigger und Grants erstellen; ausschließlich lokal/Fresh-Replay prüfen.
3. Resolver auf Standard-ALLOW plus Personenereignisse umstellen und `AdminAuthority` einführen.
4. Fachliche Call-Sites vertikal auf PermissionKeys migrieren; Fachpreconditions bleiben unverändert.
5. Reale Admin-Commands für Rechte, Status, PIN und Approval bauen; Receipt/Readback/Fault-Injection abnehmen.
6. UI erst nach Designphase 1b auf `kr-` umsetzen; Alt-Stubs und Rollenmatrix erst nach nachgewiesener Ersetzung entfernen.
7. Drei-Geräte-Browsermatrix, unabhängiger Review und Missionsgate; kein Merge/Remote/Production ohne Freigabe.
