## Migrationsgrenze

Es wurden weder Migrationen ausgeführt noch Bestandsdaten verändert. Vor Adoption ist ein gesondert genehmigtes Schema-/RLS-Paket für die connector-privaten technischen Objekte einschließlich Job-/Outbox-Tabellen nötig. Zeitgesteuerte Arbeit wird gemäß PL-Entscheidung über Supabase Cron mit DB-/Edge-Funktionen ausgeführt; die Vercel-Route queued eingehende Microsoft-Benachrichtigungen nur. Legacy-Daten werden nicht gelöscht und nicht still in die neue Wahrheit umgedeutet.
