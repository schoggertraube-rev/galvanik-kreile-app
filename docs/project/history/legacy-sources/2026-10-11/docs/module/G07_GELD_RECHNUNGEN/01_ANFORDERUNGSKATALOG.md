## Stand-Lesart

`GEBAUT` bezeichnet ausschließlich den auf `origin/main` belegten Kern. `SPEZ`, `GEPLANT` und `FEHLT` sind keine Lieferbehauptung. Offene Spezifikationsdetails sind in `08_OFFENE_FRAGEN.md` gesperrt; kein Builder darf dafür einen Default erfinden.
