The user drives this project as **chief-conductor**: they receive PL (Projektleitung)
package orders, then dispatch scoped sub-agent tasks. For this role they want
analysis/research only — explicitly "KEIN Code schreiben".

What they consistently ask for and value:
- Verification over trust: they pre-state what they believe is in the sources
  ("bereits bekannt — bitte verifizieren, nicht blind glauben") and expect the
  claim to be checked, corrected if wrong, and quoted verbatim.
- Governance anchoring checks against D-GOV-001 sources as a first-class
  deliverable, not an aside.
- Explicit `OPEN` marking instead of gap-filling; "nichts erfinden" is standard.
- Compact structured output (they often give a word budget) but completeness on
  verbatim requirements and contradictions.

They work in German; answer in German unless asked otherwise.
